# Playbooks

Repeatable processes. A process gets a playbook once it has worked on at least one
project; each playbook names the projects it was learned from.

- `monthly-cycle.md` — draft schedule for one game per month (to be validated by project 002).
- `steam-launch-checklist.md` — Steam release timeline T-8 weeks → T+30 days plus reference (assets, fests, discounts, EA, refunds); researched 2026-11-26, validate on project 002.
- `marketing.md` — per-game marketing timeline (L−8w → L+4w), wishlist/Next Fest/Boxleiter/ads benchmarks, store page, channels, catalogue compounding, pricing, metrics; researched 2026-11-26, validate on project 002.
