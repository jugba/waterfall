# Monthly release cycle (draft v0 — unvalidated)

Assumption to test: one month from concept to Steam release. Steam requires the store
page to be live ("Coming Soon") for at least 2 weeks and a review of the build before
release, so marketing must start earlier than development finishes.

| Week | Development | Store / marketing |
|---|---|---|
| 0 (prior month) | Pick concept from market research; prototype core loop | Draft store page, capsule art brief |
| 1 | Vertical slice: core loop fun and juicy | Store page live as Coming Soon; start wishlist push |
| 2 | Content production | Trailer v1, screenshots, creator outreach |
| 3 | Content complete, polish, playtests | Submit build for Steam review |
| 4 | Bug fixing, launch build | Launch, discount, post-launch patch plan |

Revise after each project's postmortem.
