# Iteration 001 — fun-check greybox v0.1.0 (hook → pull → eat → grow)
- Date: 2026-11-27
- Prompts: logged by the main session in `prompts/` (this work was a delegated subagent brief)

## Goal
A playable, tested greybox of an original premium action game on the mechanic "throw a hook, pull an
enemy in, eat it, grow and absorb its traits" (inspired by the Butcher Hero review), with Mac/Win/Linux
builds for the user's fun gate. Order of work: hook-and-eat feel → enemies/growth → evolutions/boss →
builds → docs.

## What we did
- **Theme and title:** Hookmaw (working title; options in `BRIEF.md`): Morsel, a tiny glowing deep-sea
  blob whose lure is its hook, eats its way up to the Lantern Leviathan. Top-down (360° aim, see BRIEF).
- **Rules as a node-free 60 Hz sim** (`game/scripts/core/arena_sim.gd`, `growth.gd`, `bot.gd`,
  `records.gd`, `input_frame.gd`), all tuning in `game/data/balance.json`:
  - Hook: throw to a size-scaled range (~0.2 s out), catch → hitstop, prey **struggles in pulses**,
    each **yank** is an impulse against the struggle, auto-reel otherwise, line **snaps** if a big catch
    out-pulls you, eat at the mouth. Bounces: **too big** (red ring, "need size X"), **shell front clang**,
    **spiky puffer hurts**.
  - Movement: 8-direction with acceleration, dodge with i-frames and cooldown; contact damage and
    knockback; HP regen after 2.5 s; death = restart the current wave at the size you had then.
  - Growth: size = 3·mass^(1/3); meal mass ∝ prey mass × meat × efficiency, and **efficiency falls off
    with size** (∝ size^-0.9) so growth doesn't snowball. Stats (speed, HP, range, hook speed, yank,
    reel) all derive from size + traits; world scale keeps on-screen speed constant while the camera zooms out.
  - Archetypes: nibbler (food), darter (fast, dodges hooks, dashes; SPEED), shellback (front shell, opens
    to bite; ARMOUR), spitter (keeps range, telegraphed spit; POWER = yank + chomp shockwave), puffer
    (spiky cycle; PIERCE). Trait level = 1 + floor(sqrt(eaten/3)), max 6, each level adds body parts.
  - Evolutions at sizes 8 / 15 / 25 (pause + choice of 3): **Twin/Fan Lure** (3/5 hooks), **Chain Maw**
    (catch leaps to 2/3 nearby prey), **Whirlpool** (dodge spins the hook a full circle, snags 2/4),
    **Long Line** (+30% range).
  - Waves: 9 waves (34 → 106 prey), spawned relative to your size just off-screen, next wave as soon as
    ≤ 1 hookable prey is left (no timers). Then the boss (size 46, hookable at size ≥ 41.8), which
    orbits, telegraphs charges, fires spit rings, keeps summoning snacks, and takes **4 bites** (each reel
    tears a chunk off and knocks it away).
- **View** (`game/scripts/game.gd`, `scripts/view/look.gd`, `hud.gd`, `sfx.gd`): every creature drawn
  from rounded shapes with expressive eyes (look at the aim, blink, happy ^^ on a meal, X when hurt,
  wide when hooked, angry when telegraphing); additive glow layers behind/in front; hitstop on catch /
  eat / bite; squash-stretch springs; under-damped size spring so each meal "pops"; particles; trauma
  shake (scaled by a setting); camera zoom = 2 / world-scale; aim preview dots that turn green/red;
  synthesised SFX; HUD with size (+delta), HP, wave, trait badges, banners, floaters, boss bar with
  "grow to size X", off-screen boss arrow, evolution cards and victory panel. All text ≥ 28 px.
- **Input:** mouse aim or right stick (auto-switch on last used), controller aim assist (12° cone),
  hook = J / left click / RT / RB, dodge = Space / Shift / right click / A / LB / LT; mouse buttons
  survive the settings save; new Settings: screen shake, aim assist.
- **Records** in SaveGame slot 0 (runs, wins, best time, biggest size), shown on the title.
- **Tests:** 70 GUT tests, all green (`build.sh` import + tests + 3 exports, ~11 s of tests).

## What we learned (→ memories/)
- Grow-by-eating pacing: with prey spawned relative to your size and constant meal efficiency, cubic
  mass growth snowballed (bot reached the boss gate at 1–4 min). A size-decaying efficiency (∝ size^-0.9)
  plus a bot pacing report turned it into a smooth 10-minute curve in a few tuning passes; trait levels
  on raw counts maxed out by wave 5 until they used a sqrt-of-thirds curve. →
  `memories/design/grow-by-eating-pacing-relative-spawns-decaying-efficiency-bot-report`
- GDScript: `:=` on a value read from an untyped Array element or an inner-class property is a parse
  error in 4.7, and a `-s` SceneTree script whose dependency fails to compile never quits, so headless
  runs hung until killed. Always wrap headless Godot calls in `timeout` and log to a file. →
  `memories/tech/godot-headless-script-hangs-on-parse-error-use-timeout`
- Also seen (not durable enough for a memory): when a sim pauses for a choice, clear the event list on
  `choose()` or the view re-handles the offer event and re-opens the panel.
