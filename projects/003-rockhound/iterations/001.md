# Iteration 001 — fun-check greybox (dig → crack → reveal → sell → upgrade)
- Date: 2026-11-27
- Prompts: the session's prompt file in `prompts/` (logged by the main session)

## Goal
Get a playable greybox to the user (on a Mac) within hours, to run the fun gate
(`memories/process/no-production-work-before-fun-gate-passes`). Feel over features: the first 5
minutes must have tension and reward.

## What we did
- Project set up from the template: `config/name` Rockhound, `GAME_NAME=Rockhound`, bundle id
  `com.gamefactory.rockhound`, `data/*.json` added to the export include filter, new `book` action
  (Tab / B / pad Y), placeholder player removed.
- Rules in a pure, seedable `game/scripts/economy.gd`; all numbers in `game/data/balance.json`:
  5 tiers (common 70% → legendary 0.4%), 15 crystals, 5 sets (+15–50% value), pity (rare+ within 18
  geodes, epic+ within 90), luck, shell hints (true tier 70%, else one lower), 5 upgrades with
  exponential costs, depth (12 chunks per face; value ×1.3 and rock HP ×1.22 per depth), 5-geode tray
  with bulk-selling on overflow (keeps the auto-digger earning).
- `game/scripts/game.gd`, everything drawn in code:
  - Dig: hold on the rock face; chunk hit-flash, cracks, debris, pitch rising toward breaking; chunks fall,
    geodes arc into the tray.
  - Crack: hold on the anvil; hammer swings; wobble; spreading cracks; strike pitch rises; rarer geodes take
    more strikes and leak coloured light from the cracks.
  - Reveal: shell halves fly apart, a crystal cluster pops in elastically, additive glow, rays, flash ring,
    banner (stars, tier, name, value, NEW!). Rare+ gets slow-mo and a camera push-in.
  - Polish: hold, then release in the green zone (perfect ×1.5, +0.5 per level; overshoot scratches).
  - HUD: money count-up, idle $/s, "Next:" goal bar, shop column, collection book with odds.
  - Autosave every 10 s and on quit; Continue / New game on the title screen.
- `scripts/sfx.gd`: 17 synthesised placeholder sounds (chip, break, strike, pop, five reveal chords, coin…).
  `Audio.play_sfx` gained a `pitch` argument.
- Tests: `test_rarity.gd` (distribution at ~4σ, luck, pity gap, fresh save gets rare+, shell hints),
  `test_economy.gd` (cost curve, buy/max, first upgrade ≤30 s over 20 seeds, depth, sets, tray bulk sell,
  idle income, polish, number format), `test_save_roundtrip.gd`, and a core-loop smoke test
  (dig → crack → sell → buy).
- Builds exported and zipped to `playtest/builds/`; headless captures saved to `assets/greybox/`.

## Results
- 43/43 GUT tests pass; `tools/godot/build.sh` is green (import, tests, 3 exports).
- Builds (git-ignored): `Rockhound-0.1.0-macos-universal.zip` 61 MB (ad-hoc signed universal .app),
  `-windows-x86_64.zip` 38 MB, `-linux-x86_64.zip` 28 MB.
- Captures: `assets/greybox/01-dig.png`, `02-crack-light-leak.png`, `03-legendary-reveal.png`, `04-epic-reveal.png`.
- Simulated pace: first upgrade ($15) within 30 s for all 20 seeds; rare+ guaranteed by geode 18 (~1–1.5 min).
- Not yet played by a human. Feel is checked only from captured frames.

## What we learned
- The first capture had the additive glow drawn *in front of* the crystal, which washed the payoff out
  completely. The fix was to draw the big glow behind the crystal and only a faint bloom in front →
  `memories/tech/godot-2d-glow-additive-layers-behind-and-in-front`.
- Pacing promises written as seeded tests against the JSON make retuning safe →
  `memories/design/encode-pacing-promises-as-unit-tests`.
- Release exports refuse a scene path on the command line (built with `disable_path_overrides`), so captures
  and scene checks use the editor binary with `--autoplay`.
