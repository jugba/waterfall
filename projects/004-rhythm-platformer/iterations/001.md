# Iteration 001 — Fun-check greybox: movement sandbox + one music level
- Date: 2026-11-27
- Prompts: prompts/2026-11-26_001_factory-setup.md (session log kept by the main session)

## Goal
A playable fun-check build in one session: (1) an excellent 2D platformer controller with a test
course that teaches every move, (2) one music level where an original, generated track drives the
level, synced to the audio clock. Tests for the physics promises, the beat map and a replay of the
level; Mac/Win/Linux playtest builds.

## What we did
- **Controller** (`game/scripts/core/player_controller.gd`): node-free, fixed-step, AABB collision
  against a `World` of rects (solid / one-way / breakable). Run accel/decel curves (piecewise data
  curves), variable jump (release cut), coyote time, jump buffer, apex hang (gravity ×0.45 near the
  top), fast-fall, wall slide, wall jump with control lock, wall run, dash (+1 air dash), punch with
  hitbox + lunge, glide (hold jump while falling), ceiling corner correction. Every value lives in
  `game/data/movement.json` (F5 reloads it in-game).
- **Feel layer** (`scripts/view/`): Pip, a round blob with headphones, big blinking eyes that look
  where he moves, stubby running feet, boxing glove, leaf glider; spring squash/stretch; dust on
  jump/land/wall slide; cyan afterimages and speed lines when dashing/fast; hitstop + shake + POW
  popup on crate hits; camera look-ahead with exponential smoothing and fall look-down; gradient sky,
  sun, clouds, two parallax hill layers; additive glow on collectible notes; rising pentatonic chain
  sound on quick pickups. All SFX synthesised in code (`scripts/view/sfx.gd`).
- **Sandbox** (`scripts/core/sandbox_course.gd`): run → tap/hold ledges → coyote gap → wall-jump
  chimney → wall-run cliff → dash gap → punch crates (3-high wall) → glide canyon → bounce pad +
  one-way plank + fast-fall → goal. 85 notes, 7 checkpoint flags, 10 sign boards (28 px text).
- **Music** (`tools/gen_music.py`): one script writes the original track (125 BPM, 36 bars, 70.7 s:
  kick/snare/hats/clap/crash, plucked bass, square-ish lead, pad, arpeggio breakdown; vi–IV–I–V)
  **and** `game/data/beatmap.json` (47 gameplay events: 20 jumps/long jumps, 17 punches, 5 pads, 4 checkpoints, 1 end; plus 171 notes on beats and half-beats). Each gameplay event
  also gets an audible accent exactly on its beat (kick = jump, clap = punch, boing = pad).
- **Music level** (`scripts/core/music_course.gd`, `music_run.gd`, `song_clock.gd`,
  `scripts/game/music_level.gd`): the runner's x is locked to audio time (`x = 400 px/s × t`), so
  geometry built at `x(t)` is reached exactly on the beat. Jump pits, long-jump pits, punch drums
  (with faces), bounce pads, a glide canyon, 4 checkpoints, goal. Notes are placed on their beat
  along the *simulated ideal trajectory*. Clock = playback position + time since last mix − output
  latency, predicted per frame and steered (snap > 50 ms), falls back to frame time if the audio
  clock is frozen. World pulses on every beat (sky flash, bar flash, grass tufts, drums, notes,
  near hills); PERFECT/Good ratings within ±70/±140 ms; death → count-in 4 beats before the flag,
  music re-seeked.
- Title (Movement Sandbox / Music Level / Settings / Quit) with Pip hopping on the beat; input map
  `jump`/`punch`/`dash` (A / X / B+RT) via the headless generator; controller labels (A/B/X/RT).

## What we learned (→ memories)
- A node-free AABB controller makes "feel" testable: jump heights, coyote/buffer windows and wall-jump
  direction are plain unit tests, and a whole 70 s level replay runs in ~50 ms instead of real time
  (`memories/tech/platformer-controller-as-pure-fixed-step-sim-for-tests`).
- Locking an auto-runner's x to audio time turns "on the beat" into "in the right place"; generate the
  music and beat map from one script and test the onsets; place collectibles on the simulated ideal
  path (`memories/design/rhythm-runner-lock-x-to-audio-clock-and-test-replays`).
- First glide tuning (fall 115 px/s at 1.05× run speed) overshot the 820 px canyon by a whole mesa;
  140 px/s at 0.95× steers onto it. The course tests caught it.
