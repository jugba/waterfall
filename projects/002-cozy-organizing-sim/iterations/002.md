# Iteration 002 — Greybox vertical slice of the core loop
- Date: 2026-11-26
- Prompts: prompts/2026-11-26_001_factory-setup.md (greybox prototype request, delegated to a subagent)

## Goal
A greybox prototype of one Knolling Co. job, good enough for the week-1 go/no-go playtest
("is it fun in 5 minutes?") and for a greybox clip of the hook (tip → tidy grid → score).

## What we did
- Renamed to "Knolling Co. (prototype)" (window, export product name, title screen);
  `GAME_NAME=KnollingCo`. Template foundations kept (settings, save, audio, scene changer,
  pause, Steam no-op). The template's placeholder player was removed.
- Data-driven content: `game/data/items.json` (38 items: id, name, w×h cells, category, colour)
  and `game/data/jobs.json` (3 jobs: pencil case 8 items, junk drawer 14, day pack 22), loaded by
  `scripts/catalog.gd`. Included in exports via `include_filter="data/*.json"`.
- Loop in `scripts/game.gd`: client note → **tip** (container wobbles and tips, items pour
  out with velocity/spin, bounce off the mat edge, push apart; screen shake, thunk + rattle) →
  **sort** on a 32×20 grid (`scripts/desk.gd`) → **photo** (flash, camera frames the desk,
  score card counts up, stamp, confetti, one line per scoring reason with points) → **pack back
  (STUB)**: items fly back into the bag by themselves, lid closes → payday, Next / Retry / Title.
  Progress (next job, best score per job, money) saved in SaveGame slot 0.
- Juice: lift + bigger shadow and drag wobble while held, straighten-on-pickup, drop ghost +
  dashed alignment guides, back-ease snap tween, landing squash, dust puff, click pitched by item
  size plus a second higher click when it lines up with a neighbour, loose items get kicked away
  by a drop, live neatness meter that pops when it rises. Sounds are synthesised placeholders
  (`scripts/sfx.gd`); `Audio.play_sfx` gained an optional base `pitch` argument.
- Controls: mouse drag, right-click/wheel rotate 90°; controller stick cursor, A grab/drop,
  d-pad jumps to the next item in that direction (or nudges the held item one cell), LB/RB rotate,
  Y photo; keyboard WASD/arrows, Space, Q/E/R, Enter/F. New actions `rotate_cw`, `rotate_ccw`,
  `finish_job` (key + pad, device -1) added to the InputMap and the rebinding menu.
- Freeform scorer `scripts/neatness.gd` (no target layout): square to the desk + parallel long
  items (20), aligned rows/columns (30), even spacing with overlap penalty (25), grouping by type
  or colour vs chance (25). Reasons are shown on the score card.
- Tests: `tests/unit/test_neatness.gd` (tidy high, scatter low, two different tidy layouts both
  high, snapped-random in between, overlap/tilt penalties, reasons sum to total),
  `tests/integration/test_job_flow.gd` (data valid; each job loads → tips → arranges → photo ≥85 →
  packs → saves; drop snaps without overlap; rotation; controller grab/nudge/drop; reveal UI).
- Debug-only `--autoplay [--job=N] [--seed=S]` user arg plays a job by itself (used for capture).

## Results
- `tools/godot/build.sh projects/002-cozy-organizing-sim`: **35/35 tests pass**; Linux
  (73.6 MB) and Windows (109 MB) exports succeed and contain the job data. Build outputs removed.
- Scores: tipped mess 18–24; auto-arranged rows by type 95–97; vertical colour columns 89–94.
- Greybox frames (job 3, 22 items): `assets/greybox/01-intro.png` … `06-score-reveal.png`
  (rendered with Xvfb + `--write-movie`, see `memories/tech/godot-headless-capture-xvfb-write-movie`).
  A 14 s mp4 with sound was made in the session scratchpad only (not committed).
- Not playtested by a human yet; feel and controller handling are untested on real hardware.

## What we learned
- Centre-distance kNN undervalues tidy rows; grouping needs aligned neighbours at the smallest gap
  → `memories/design/knolling-scorer-groups-by-neighbours-at-smallest-gap`.
- Real rendered captures work in the container → `memories/tech/godot-headless-capture-xvfb-write-movie`.
- Give each moving node a single "motion" tween that new moves replace; a grab tween still
  running cancelled a rotation (caught by a test).
