# Rhythm tags beat the base rate while platformer tags are saturated; pitch a rhythm-platformer as a rhythm game

- Area: market
- Date / source: 2026-11-27, projects/004-rhythm-platformer/research/market-check.md §1, computed from projects/001-steam-market-research/research/processed/candidates.csv + games_analyzed.csv (research/processed/tag_combo_rates.csv)
- Confidence: medium (1–12 hits per tag; top-7 tags only; one 12-month window)
- Apply when: choosing tags, store positioning or the audience for any platformer, runner or music game.

Core-hit lift vs all 30,708 releases (base 8.1 core hits /1000):

| Tag set | Releases | Core lift |
|---|---|---|
| 2D Platformer | 1,893 | 0.19× |
| Any platformer tag | 3,755 | 0.39× |
| Rhythm | 361 | 1.36× |
| Music | 151 | 2.44× |
| Rhythm/Music + Cute/Colorful | 73 | 3.4× (n=2) |
| Platformer + Rhythm/Music | 52 | 0 (40 have 0 reviews, best 184) |

No linear, level-based 2D platformer became a core hit. Every platformer hit is a hybrid (metroidvania, incremental, puzzle, collectathon) or brand/IP/sequel. Rhythm hits pair the beat with another genre and name what the beat controls.

Lead the store page with Rhythm/Music tags, not Precision Platformer/Difficult. The intersection is an empty niche, not a proven one.
