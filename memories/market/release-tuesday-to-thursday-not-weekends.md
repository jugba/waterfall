# Release on Tuesday–Thursday; weekend releases almost never become hits

- Area: market
- Date / source: 2026-11-26, projects/001-steam-market-research (iteration 002): research/processed/analysis.md, reports/market-report.md
- Confidence: medium (correlational: hobby and asset-flip releases cluster on weekends)
- Apply when: picking a launch day.

Successes per 1,000 releases by weekday:

| Weekday | Successes /1000 |
|---|---|
| Thursday | 26.5 |
| Tuesday | 20.3 |
| Wednesday | 18.2 |
| Friday | 14.4 |
| Monday | 13.1 |
| Sunday | 5.7 |
| Saturday | 3.7 |

There is no strong month effect for small-scope hits; April was the peak. Pair the weekday with the sale cutoffs in marketing/steam-release-blocks-discounts-30-days.
