# A pure "put it back on the shelf" game is now a clone; give organizing a second verb or a new view

- Area: design
- Date / source: 2026-11-26, projects/002-cozy-organizing-sim/concepts.md §1.2 (data: projects/001-steam-market-research/research/processed/candidates.csv, games_analyzed.csv)
- Confidence: medium (tag counts use only each game's top ~6 tags; Q4 is young)
- Apply when: choosing the core verb of a cozy/organizing/job-sim game, or re-checking a hot tag.

Releases tagged Organizing per quarter in 2026: 7 → 15 → 60 → 192 (Q4 = only ~8 weeks); Job
Simulator 23 → 30 → 40 → 274; 143 window releases have "Tidy" in the title. Most clones are $4.99–5.99
first-person shelf-fillers earning ~$100–300k est. net each.
The earners per game add a craft or a second verb with fidelity: Dressmaker (cut, sew; $14.99,
$6.0M est.), ReStory (disassemble, repair; $19.99, $4.8M), Cat Mail Co. (sort + weigh + label + stamp;
$14.99, $2.1M). So: pick a verb beyond pick-and-place (craft, repair, deduce, pack) or a view the clones
don't use, and re-measure a tag's lift before each new project in that tag — lifts fade as copycats arrive.
