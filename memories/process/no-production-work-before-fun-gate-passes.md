# Don't start store page, art or polish until the week-1 fun gate passes

- Area: process
- Date / source: 2026-11-27, projects/002 — store page, art direction and polish ran in parallel
  with the playtest; all wasted when the playtest said no-go.
- Confidence: high
- Apply when: planning parallel work during a game's first week.

Before the gate, only work on the prototype and on deadline-driven paperwork (Steamworks onboarding,
fees). Get a playable build to the user within about 1–2 days so the gate happens early.
