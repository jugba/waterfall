# Memories

Durable learnings that should change how we work on future projects. Not a diary —
the diary is `projects/*/iterations/`.

## Files

| File | What goes in it |
|---|---|
| `INDEX.md` | One line per memory, so a session can scan everything in a minute. |
| `market.md` | What sells on Steam: genres, prices, tags, timing, competition. |
| `design.md` | Game design and polish lessons (feel, onboarding, scope). |
| `tech.md` | Engine, tooling, build, performance, Steamworks integration. |
| `marketing.md` | Store page, capsule art, trailers, wishlists, festivals, creators. |
| `process.md` | How we work: scheduling, scoping, prompting Claude, reviews. |

## Entry format

```markdown
### M-NNN: <one-line learning>
- Date / source: 2026-11-26, projects/001 iteration 002 (link or evidence)
- Confidence: low | medium | high
- Apply when: <the situation where this should change a decision>
```

Update or retire an entry when newer evidence contradicts it — note why, don't silently delete.
