# Steam Next Fest is once per game and needs an unreleased game with a public demo — assign each fest to a specific upcoming game

- Area: marketing
- Date / source: 2026-11-26, https://partner.steamgames.com/doc/marketing/upcoming_events/nextfest ; https://partner.steamgames.com/doc/marketing/upcoming_events/nextfest/feb_2027 ; https://partner.steamgames.com/doc/marketing/upcoming_events/nextfest/june_2027
- Confidence: high (rules official; "must be unreleased" is from third-party guides)
- Apply when: picking release months and deciding whether a game needs a demo.

2027 editions: Feb 22 – Mar 1 (register by Jan 10, 11:59pm PST), Jun 14 – 21 (deadline not yet
confirmed), October (dates TBA). Requirements: public Coming Soon page, separate Demo app playable by
the fest start, registration from the base game. A game may appear only once. With one game per
month, only the game(s) launching shortly after a fest can use it, so pick them deliberately and
build their demo a month earlier.
