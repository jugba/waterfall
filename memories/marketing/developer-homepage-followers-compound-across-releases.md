# Link every game to one Steam Developer Homepage before its page goes live; homepage followers are our compounding audience

- Area: marketing
- Date / source: 2026-11-26, desk research. Steamworks Creator Homepage docs (acc. 2026-11-26, https://partner.steamgames.com/doc/store/creator_homepage); Valve announcement 2018 (https://store.steampowered.com/oldnews/20845); Zukowski 2023-05-01 (https://howtomarketagame.com/2023/05/01/what-is-the-difference-between-a-steam-wishlist-and-a-follower/); Steamworks bundles (https://partner.steamgames.com/doc/store/application/bundles)
- Confidence: medium-high (the mechanism is documented by Valve; the size of the effect is untested for us)
- Apply when: creating any new Steam app, and planning launch-day cross-promotion.

Followers of a developer or publisher homepage get an email when we release a new game. Per-game followers get no launch email.

A monthly cadence turns this into a flywheel:
- Put a "follow us" call to action in every game, event and video.
- Post on every older game's page when a new game launches.
- Keep a Developer/Franchise bundle with complete-the-set pricing and add each new game at launch.

Track homepage followers as a factory-level KPI. Apps created after the homepage exists must be linked to it manually.
